# @wjdghks963/pixel-actors-core

Core engine for Pixel Actors.

- Sprite/frame types
- frame-to-box-shadow conversion
- keyframes generation
- hash + fps clamp utilities

## Install

```bash
npm i @wjdghks963/pixel-actors-core
```

## API

```ts
import {
  frameToBoxShadow,
  spriteToKeyframes,
  createHash,
  clampFps,
  type Sprite,
  type Frame,
  type Pixel
} from "@wjdghks963/pixel-actors-core";
```
